# DDT magnetism induction

DDT solenoid magnetic field. B = mu0*n*I where n = N/l. Convert l to metres and use mu0 = 4*pi*1e-7 H/m.

DDT solenoid proportionality. For fixed length, B is proportional to number of turns N and current I. For fixed N, B is inversely proportional to length l.

DDT magnetic flux. Phi = B*A*cos(theta), where theta is the angle between B and the surface normal. If B is perpendicular to the surface, theta = 0.

DDT induced EMF. Use abs(e) = abs(Delta_Phi/Delta_t) for one turn and abs(e) = N*abs(Delta_Phi/Delta_t) for N turns.

DDT Lenz law. The induced current direction opposes the change in magnetic flux. For direction questions, answer qualitatively with the opposition principle.

DDT self induction. e = -L*dI/dt. For uniform current change, abs(e) = L*abs(Delta_I/Delta_t).

DDT inductance of solenoid. L = mu0*N^2*A/l. Convert area to m^2 and length to m.

DDT energy in inductor. W = 0.5*L*I^2. If current doubles, energy becomes four times larger.

DDT magnetic energy density. w = B^2/(2*mu0). Energy density scales with the square of B.

DDT Lorentz force. F = q*v*B*sin(alpha). Direction follows the right-hand rule for positive charge and reverses for negative charge.

DDT force on current wire. F = B*I*l*sin(alpha). If the wire is parallel to B, force is zero.

DDT qualitative proportionality. If the question asks proportional to what, answer with variable relationships rather than inventing numbers.

DDT change questions. If current is doubled in a solenoid, B doubles. If turns per length doubles, B doubles. If length doubles with fixed turns, B halves.

DDT flux angle trap. Use angle with the normal, not with the plane. If angle is given with the plane, convert to the complement.

DDT Faraday sign. Numeric magnitude usually uses absolute value. Direction or sign questions need Lenz law.

DDT unit traps. T for magnetic field, Wb for flux, H for inductance, V for induced EMF. Area in cm^2 must become m^2.

DDT moving rod EMF. For a rod length l moving speed v perpendicular to B, e = B*l*v. Include sin(theta) if not perpendicular.

DDT transformer relation if present. For ideal transformer, U1/U2 = N1/N2 and I1/I2 = N2/N1.

DDT if magnetic field changes linearly, average induced EMF equals N*abs(Phi2-Phi1)/Delta_t.

DDT if loop area changes, Delta_Phi = B*Delta_A*cos(theta) for constant B and angle.

DDT if field direction reverses from +B to -B, flux change magnitude is 2*B*A, not zero.

DDT if asked characteristics of magnetic field in a long solenoid, field inside is nearly uniform and directed along the axis.

DDT if asked direction around straight wire, use right-hand grip rule: thumb current, curled fingers magnetic field.

DDT if asked force between parallel currents, same direction attracts and opposite direction repels.

DDT answer_type is qualitative for direction/proportionality/change description, quantitative for B, Phi, e, L, W, F.

DDT final sanity check: increasing current should not decrease B in a linear solenoid model.
